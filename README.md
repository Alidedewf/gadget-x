# GadgetX Market

Мобильное e-commerce приложение для покупки гаджетов, разработанное с использованием современных кроссплатформенных технологий.

## Технологический стек

*   **Фреймворк:** React Native
*   **Инструментарий:** Expo
*   **Язык:** TypeScript

## Основной функционал (MVP)

*   Каталог гаджетов
*   Карточки товаров с детальной информацией
*   Корзина покупок
*   Избранное (Favorites)

## Инструкция по запуску

1. Убедитесь, что у вас установлены Node.js и npm.
2. Установите зависимости проекта:
   ```bash
   npm install
   ```
3. Запустите проект через Expo:
   ```bash
   npx expo start
   ```
После запуска вы можете открыть приложение на физическом устройстве через Expo Go (сканировав QR-код), либо в симуляторе iOS/эмуляторе Android.
